# 工作台组件开发

## 产品边界

- 所有卡片（含 `resume / queue / today`）在一个统一网格中，阅读态不接受拖拽。
- React Grid Layout 只负责移动时的像素跟手，resize 保持关闭；全部用户改尺寸交互取消，不提供尺寸手柄、下拉或键盘尺寸切换。新实例用组件的 `sizing.default`，保存尺寸不自动转换。自定义 compactor 从每次移动拖起时快照计算局部碰撞让位预演，不全局压实，保留未涉及的留白。
- 候选位置带近边对齐与迟滞；碰撞目标稳定停留 500ms 才确认让位，同格移动不重置，换格或离开重新计时。提前松手回到拖起快照；无碰撞空位立即可放。
- 碰撞集合共用一个轴：单目标用归一化指针偏移，多目标用总脱离距离；上方同排一起上移、下方下移，左右镜像。仅沿选定轴传播，跨轴坐标与原相对顺序是硬约束；首选分流可行时保持不变；边界不足时仅尝试同轴的有序分割（同排/同列组不拆），按最少偏离首选及最小位移选择。首选轴完整无解后，才对另一轴独立求解一次；每个结果仍只有一个轴，保留该轴的跨轴坐标、同行同列分组和原顺序，不混轴、不自由重排；两轴均无解才拒绝。
- 拖拽视觉几何与可提交布局分离：active 视觉位置仅由指针候选决定，碰撞只移动非 active 项。待确认 / 无法放置时绝不回写候选；松手拒绝时用 epoch 重挂载收敛引擎，避免旧重叠 visual 被内部 stop 留下。手势期间保持画布高度上界，防止收缩引起视口跳动。
- 静止指针也能由确认定时器触发预演；拖回原位时邻居恢复。只在松手提交整份预演，Esc / blur / touchcancel 取消整个事务并清理 timer。
- 页首进入 / 完成编辑，标题与移动把手可拖；正文 inert，卡片右上角只剩移动把手；删除是把手拖到页首「拖到这里删除」目标（指针进入即变红、松手立即删除并播放碎屑），键盘等价路径是把手聚焦后按 Delete / Backspace；另有显式整理布局；独立删除确认弹窗等待落盘。当前组件库原型去掉隐藏、复制和实例清单，无尺寸控件或本地尺寸预览 / 错误状态。
- 完成等待保存成功。旧 order/size/focusOrder 投影成初始矩形；positions 按 12/6/2 列断点分别保存 x/y/w/h，不覆盖其他断点、隐藏或缺席插件的记录。
- 新扩展通过可选注入的 `homeWidgets` 注册 API v1 类型；内置卡与第三方类型共用实例路径，不自动实例化目录中的新类型。公共契约以[小组件开发指南](<widget-development.md>)为准。
- 持久化实例为 `{ instanceId, typeId, configVersion, config }`；同类型可多实例；历史隐藏不删除，确认删除才清理全部断点记录。Content 自己提供配置入口，saveConfig 成功后正文切换；外壳不渲染 Settings。
- 旧 `home.widget` 仅由内部适配器保留 `{ size }` props；新安装贡献只进入目录，由用户添加。v2 布局引用过的第三方 id 按 `legacy:<id>` 迁移，不依赖当时是否安装。
- 旧 `order / size / hidden / focusOrder` 和各断点覆盖保留；类型缺失、配置迁移失败或未来版本保留原记录，以占位 / 单卡错误展示，不静默重置。
- `WidgetGallery` 是侧边真实内容预览库，名称 / 说明 / 来源 / typeId 搜索与内置 / 扩展筛选；直接拖标题或把手，不提供 Add 或额外放置模式。`preview.config/data` 提供样例，`ContentProps.preview` 标记隔离预览；没有样例时 config=默认、data=null。内置 preview provider 不构造 HomeStore，预览不请求活动 API 或启动时钟计时器。旧静态 Preview 忽略，第三方必须适配 preview 停用副作用。
- `.dsh-home-inner` 跟随宿主可用宽度，不再固定上限；不更改网格坐标或主动压缩留白。宽度变化只触发已有 12/6/2 列投影，不因浏览目录保存位置。
- 每个 widget 用对象声明自己的有限组合，如 `sizing: { default: { w: 4, h: 6 }, supported: [{ w: 4, h: 6 }, { w: 7, h: 9 }] }`；`w` 为整数 `1..12`、`h` 为整数 `3..30`，1..16 个不同组合，默认按 `w/h` 匹配；注册时克隆并深度冻结。不存在宿主统一尺寸目录。0.17 字符串只兼容解析任意合法 `WxH`，不推荐给新代码或向用户展示为目录。6 列宽投影 `w <= 4 ? min(w, 3) : min(w, 6)`、2 列 `min(w, 2)`，高度不变，实际重复形状合并。
- 新建与组件库拖入采用 `sizing.default`；`sizing.supported` 和旧 `defaults` 仅保留兼容元数据，不再提供用户可切尺寸。移动把手方向键仍逐格移动；不挂载 WidgetResizeHandle，也不维护 page local resize preview / error 或尺寸手柄样式。底层兼容模型不等于用户交互入口。
- 旧 `defaults` 校验后保留宽桶与真实 height 推导默认组合，无 ceil / 截断，旧 bounds 不定义用户可改尺寸。已保存的全部合法矩形（含旧宽1/2和声明外形状）原样保留，普通移动与显式整理不转换，不自动 reset 或 rearrange。只有旧 order/size、所有断点均无坐标的实例仍走历史 size-only 兼容；不以新默认值重新解释。API v1 与 x/y/w/h 持久化格式保持不变。公共契约以[小组件开发指南](<widget-development.md>)为准。

## 数据与操作

- `session-model.ts` 合并客户端会话目录与活动账本，目录不依赖账本整理完毕。
- 客户端 `parentId` 在 store 中转为内部 `parentSessionId`；任一来源证明空白或子代理时排除。
- 最近活动取有效的 `updatedAt / lastAt` 最大值，未知时间放到末尾，不伪造当前时间。
- 状态读取实时 `pendingInteraction.kind`，兼容旧字符串；`running: false` 只表示空闲，不代表完成。
- 目录短名使用可区分路径后缀，完整路径、会话 ID 保留在 tooltip；搜索匹配完整值。
- 草稿入口通过 `workspaces.create({ path })` 登记已有目录，再调用 `uiWorkspace.startSession`。
- 使用 `whenDraftExists: 'append'`，不覆盖已有输入，不调用模型提交接口。
- `startSession` 返回 void；异步导航失败由宿主提示，组件不能将 Promise resolve 当作导航完成。
- 目录选择使用宿主 picker，不自行扫描文件或创建目录。

### 小组件数据分层

- `widget-contract.ts` 仅公共类型与 Cordis Context 增补，分发到 `lib/types/widget-contract.d.ts`；扩展只用 `import type` 导入 `@vlln/dsh-home/widgets`，不运行时 import Home。
- `widget-registry.ts` 是无 React runtime / store / geometry 依赖的纯注册表：原子拒绝重复、稳定冻结快照、scope effect 持有撤销函数；配置工厂独立克隆，校验 / 迁移只支持同步。
- JSON 上界与持久化一致：UTF-8 序列化 8 KiB、深度 8、4,096 节点、键长 256；拒绝危险原型键、非 JSON 值和可执行属性。具体默认尺寸 / props / 失败语义见公共指南，不在各内置卡重复实现。
- `HomeStore` 通过 `workbench.get/set` 一起加载 / 串行写入实例与布局；读取失败进入只读诊断，不覆盖成默认值。设置写失败保留原配置，后续重试不被失败队列污染。
- 公共类型注册与持久化无强绑定：类型撤销保留实例，迁移失败返回原始实例及诊断；不要因缺席类型而裁剪存储。

## 计划数据（0.32.0 起）

- 待办 / 今日计划 / 日程 / 打卡是**同一份数据的四个视图**：`$DSH_HOME/data/dsh-home/planner.json`。条目字段 `{ id, kind, title, day, start, end, done, doneAt, priority, note, createdAt, updatedAt }`，习惯另存 `{ id, title, weekdays, marks, createdAt }`。
- 写入是 op 式的（`planner.apply` + `operation`）：宿主在现有文档上应用并回传整份文档，客户端不重复实现 op 语义。两个窗口同时改不会互相覆盖，因为没有任何一端提交「整份覆盖」。
- 上限：条目 500、习惯 30、标题 200 字、备注 2000 字、打点每习惯保留 400 天、文档 512 KiB。超限返回类型化错误码，不写坏文档。
- 落盘沿用 `state.mjs` 的 `.tmp` + `rename`。文件损坏时 `planner.get` 返回 `storage.writable=false`，组件显示「数据不可用」；**不改写原文件**，且每次读取都以磁盘为准，所以把文件修好后无需重启宿主即可恢复。
- 客户端共享层 `home-data.ts`：模块级 store + `useSyncExternalStore`，页面挂载读一次、回到可见时补一次，不轮询。任何一处写入后别处同一帧重渲染。
- 计时数据另存 `focus.json`，只记 `startedAt + accumulatedMs`，剩多久由前端按墙钟算；番茄钟按「一轮一个阶段」结算，关页面到点只结算一轮并停在下一阶段起点，不追补。倒计时按「目标日 0 点」结束，不足一天时显示时分。
- 所有计划/计时组件在 `preview` 分支只读合成数据，不发请求、不订阅、不起计时（`scripts/verify-planner.mjs` 用请求计数断言）。

## 视觉约定（0.39.0 起）

- 图表用「粗、实心、高饱和」：番茄钟环 14/120、Token 甜甜圈环宽 14px、柱状纯色无渐变、勾选/打点/选中日都是实心色块 + 白字。
- 宿主 token 只有蓝/绿/琥珀/红四个色相，参考图需要更丰富的配色，因此在 `.dsh-home` 作用域里补了 `--dsh-hue-{blue,teal,green,amber,violet,pink}`（固定中饱和色，深浅背景都可读）。**UI 骨架仍只用宿主语义 token**，额外色相只用于图表与分类。
- 分类色：习惯按 id 哈希固定色相；日历圆点按当天未完成数量取蓝/琥珀/粉；条目优先级 → 琥珀/红圆点；Token 甜甜圈按 input/cacheRead/output/cacheWrite 取蓝/绿/琥珀/紫。
- 这套主题里 `--dsw-alias-bg-layer-2/3` 都是纯白、`--dsw-alias-label-quaternary` 不存在，浅面用 `bg-skeleton` / `interactive-bg-hover`，淡字用 `label-caption`，饱和底上的字用 `label-primary-foreground`。

## 组件收敛与预览单源（0.40.0 起）

- **下线类型在读取时迁移**：`src/widget-state.mjs` 的 `RETIRED_WIDGET_TYPES` 删除「常用任务」「回到现场」，把「在等我」并入 `@vlln/dsh-home:running`（已有 running 实例时直接丢弃队列实例）。`state.mjs` 的 `loadState` 在返回前裁剪实例，并同步清掉 `order / focusOrder / hidden / size / positions` 对它们的引用，所以升级后不会留下「未知组件」卡片；迁移结果随下一次正常写入落盘，旧文件复制为 `state.json.v2.bak`。`BUILTIN_WIDGET_IDS` 只影响新装，老布局靠这条迁移。
- **会话状态**：`running` 类型改名为「会话状态」，配置 `{ status: 'running' | 'waiting' | 'done' | null }`。`null` 表示自动——展示第一个有内容的视图；点顶部胶囊后写入具体值，刷新保留。三类映射与官方 `sessionStatus` 一致（待审批 / 待确认计划 / 待回答 / 跑完没看），「在等你」的行显示原因并可 dismiss（静音到下一次活动，未知活动时间不当作已看过）。宿主没有该钩子时只显示「在跑」并说明。
- **预览单一来源**：组件库没有插图分支。`widget-preview.tsx` 用定义声明的默认网格尺寸算出真实卡片像素（`preview-geometry.ts`，与画板的 84/44 + 12 间距同一套公式），把同一个 `Content` 放进同一个 `.dsh-w-body`，最后只对整块做视觉缩放。布局因此看到真实卡片的宽高，容器查询、分批行数和图表不会在预览里漂移；`width/height` props 仍是真实卡片尺寸，数据仍是合成样例。
- **便笺 v2**：配置从 `{ title, text }` 变为 `{ text }`，`migrateConfig` 把旧标题并成第一行（中间空一行）。卡片内原地编辑，首行渲染为加粗标题；停笔 0.6 秒或失焦保存；超过 8 KiB 或宿主拒绝时保留草稿并显示原因，不覆盖原文。
- **最近活跃 v2**：删掉「今天」窗口（它是 24 小时时间带，不是柱状）与页脚；旧配置 `today` 迁移到 `7d`。柱子用宿主 `Tooltip`（portal）在悬停/聚焦时给出日期与时长。
- **计时器不再等数据**：`focus` 文档未就绪时先画 00:00 并禁用按钮，就绪后启用；读取失败显示重试，不再有「永远正在读取」。
- **计时器（0.42.0 起）**：倒计时圆盘。`targetMs` 存在 `focus.json` 的计时槽（`timer.target` op，1–60 分钟），不放在实例配置里——配置一变卡片会因边界键重挂，拖动会被打断。圆盘是 `role="slider"`：空闲时拖动圆环按角度设时长（12 点 = 60 分，顺时针一圈），4px 阈值保证单击不改值；方向键 ±1、PageUp/Down ±5、Home/End 到端点。拖动只改本地预览，松手才写一次；指针在圆盘任意位置（含中间数字）滚轮 ±1 分钟（Shift ±5），右侧 5/10/15/25/45/60 分钟预设一键设定，非 passive 的 wheel 监听顺手阻止卡片滚动。启动后不可拖，只有 Pause/Reset；暂停是 Resume/Reset；到点自动 `timer.pause` 并显示「到点」，可重新开始（reset→start）或归零。实例配置升到 v2（空对象，v1 的 `label` 丢弃）——圆盘中间只有数字。
- **工作足迹筛选（0.43.0 起）**：尺度与工作区从设置弹窗移到卡片底部，用和时钟时区同一套 `.dsh-quiet-select`（11px 小字 + 小箭头，无边框）；热力图每块改为 Portal 的 `.dsh-hover-tip` 悬停气泡（日期 · 消息数 · 会话数），不再依赖原生 `title`。点击某天仍打开当天会话明细。
- **时钟（0.41.0 起）**：配置只剩 `{ timeZone }`（v3，旧 `label`/`hour12` 迁移时丢弃），时区是下拉而不是输入；12/24 制交给 locale（en-US 12 小时、zh-CN 24 小时）。卡片删掉标签行、整行日期与「时间选项」按钮，4×4 卡片不再出现滚动条。0.42 起时区入口进一步收敛成一行 11px 的灰色小字 + 小箭头（无边框、无底色），默认项叫「跟随浏览器」，悬停 title 才给具体时区。
- **列表不再用负外边距**：`.dsh-rows` 的 `margin: 0 -8px` 在固定卡片里会制造 8px 横向滚动条（最小组成卡片可见），已去掉；工作区名改成实心胶囊，行顺序是状态点 → 胶囊 → 标题 → 时间。

## Token 与余额（0.34.0 / 0.36.0 起）

- 账本在折叠事件时按天累计 token：`assistant/message` 的 `data.usage`，重试走 `assistant/attempt` 流里最后一个 usage chunk（与宿主 `token-meter` 的 `usageOf` 同口径）；同一 turn/step 的新样本替换旧样本，`llm/retry-started` 撤销上一份，避免重复计数。`FOLD_VERSION` 也随之升到 4，旧账本自动整份重折。
- 速率 = 当日输出 token ÷ 当日运行时长；没有运行时长时显示 `—`，不拿别的数凑。
- 余额走宿主 `/api/dsh-home/balance`：key 只在宿主侧解析（`settings.describe()` 里声明的 `apiKeyEnv` 引用 → `credentials.resolve`，兜底环境变量），`fetch` 平台接口，浏览器只拿数字；失败回原因，不缓存旧值。
- 本地图片走宿主 `/api/dsh-home/image`：只读、扩展名白名单、20 MB 上限，整条路由在 owner 围栏之后。

## 显式整理与组件自有编辑

- `compactSpatialLayout` 仅由编辑模式「整理布局」调用。视觉顺序优先、逐卡 row-major first-fit，保留尺寸和元数据；已局部紧密的结果 no-op，普通拖动仍不压实。形状受限残洞可能保留，不承诺全局最优 / 无缝铺满。
- Store 整理入口拒绝非法、过期、只读、忙或实例集不完整的快照，只写当前断点，保留不可见实例及其它布局。Reset 用户入口和 store.reset 已删除。
- `Content.saveConfig?` 是持久化能力，非打开设置命令。内置组件显式选择自己的按钮与编辑器；第三方自行实现，Settings 字段兼容但不被外壳渲染。删除使用官方 Modal 与取消初始焦点。
- 当前控件专项：`DSH_VERIFY_URL='<private-instance-url>' node scripts/verify-layout-controls.mjs`；原拖拽组件库脚本已适配组件自有编辑和独立删除弹窗。

## 隔离宿主回归

先构建本地 tarball，不需要 `npm publish`。从仓库目录执行：

```sh
npm pack --pack-destination ../.work
# 0.4.0 历史全域验证脚本（包含旧布局选择器，不适用于新编辑模式）
node scripts/verify-host.mjs --tarball ../.work/vlln-dsh-home-0.4.0.tgz --run
# 0.4.1 历史排序式编辑回归
DSH_VERIFY_URL='<private-instance-url>' node scripts/verify-editor.mjs
# 0.5.x 历史碰撞阻止式布局回归
DSH_VERIFY_URL='<private-instance-url>' node scripts/verify-spatial.mjs
# 当前实时碰撞让位回归；唯一证据目录备份原布局并在 finally 还原
DSH_VERIFY_URL='<private-instance-url>' node scripts/verify-collision.mjs
```

执行时使用受管理的后台任务。脚本固定私有站点端口，结束时关闭自建进程，不连接主 GUI，不读取用户模型凭据或真实会话。端口、日志与站点目录由脚本推导，不复制机器绝对路径到本文件。

## 固定列宽画布（2026-11-06，0.24.1 / dsh 0.2.1-rc.5）

用户诉求：组件像素尺寸不得因为画布或窗口变化而改变；接受横向滚动。这替换了 0.23 的「等比缩放 + 边缘保留」模型。

- 列宽固定：列内容 84px + 间距 12px = 步距 96px；行高仍 44px + 12px 间距。组件像素宽 = `w*84 + (w-1)*12`，与画布、窗口都无关（实测 372px / 756px 在 12→32 列全程不变）。
- 列数由画布宽度偏好决定，与窗口无关：`cols = clamp(floor((W+12)/96), 12, 32)`；板宽 = `cols*84 + (cols-1)*12`（12 列 1140 … 32 列 3060）。拖动时预览原始宽度，提交时吸附到整列（`cols*96-12`），因为「多放几列」本身要求整列边界。
- 窗口比画板窄时 `.dsh-home` 横向滚动，文档本身不溢出；窗口更宽时画板居中。旧的 12/6/2 窗口断点不再参与运行时：窄窗口滚动，而不是重新投影成 6 列 / 2 列。旧 `positions["6"]/["2"]` 数据保留可读，不迁移、不删除。
- 位置按当前列数存 `positions[String(cols)]`；该键没有数据时按「最近的已存断点」原样读取（优先 ≤ 当前列数中最大者，否则最小者），**不缩放坐标**。所以把画布从 12 列调宽不会移动任何组件（实测 6 个组件在 13 列下坐标与 12 列数据逐一对应）。超出当前列数的旧矩形仍走既有的重新找位路径，不会丢失。
- 连带修正的四处运行时/持久化假设：`state.mjs` 保存时按 `[12,6,2]` 过滤会把 13+ 列位置丢弃（改为接受 1..32 且保留旧键）；`store.ts` / `library-drag-model.ts` / `widget-sizing.ts` 的 `[2,6,12]` 守卫（13 列会抛错或把宽度压到 2 列）；以及**拖拽求解器** `collision-preview.ts` / `multi-preview.ts` 里 `cols <= 12` 的隐性上限（13 列时落点被判非法、拖入直接被拒——这轮浏览器回归抓到的真实回归）。
- 384 项单测、类型检查、构建通过；新增「固定步距下组件像素宽恒定」「13/16/24/32 列接受完整宽度几何」「workbench 往返保留 13..32 键」「换列数时读最近断点、放不下的矩形重新找位而非丢失」等用例。浏览器 7 个专项通过（画布宽度、视觉、组件库、释放、画布延展、固定尺寸、置顶），并单独实测 12/13/16/24/32 列下组件宽度恒为 372/756、709px 窗口下画板滚动而文档不溢出。
