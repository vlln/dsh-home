# 工作台组件开发

## 产品边界

- 所有卡片（含 `resume / queue / today`）在一个统一网格中，阅读态不接受拖拽。
- React Grid Layout 只负责移动时的像素跟手，resize 保持关闭；全部用户改尺寸交互取消，不提供尺寸手柄、下拉或键盘尺寸切换。新实例用组件的 `sizing.default`，保存尺寸不自动转换。自定义 compactor 从每次移动拖起时快照计算局部碰撞让位预演，不全局压实，保留未涉及的留白。
- 候选位置带近边对齐与迟滞；碰撞目标稳定停留 500ms 才确认让位，同格移动不重置，换格或离开重新计时。提前松手回到拖起快照；无碰撞空位立即可放。
- 碰撞集合共用一个轴：单目标用归一化指针偏移，多目标用总脱离距离；上方同排一起上移、下方下移，左右镜像。仅沿选定轴传播，跨轴坐标与原相对顺序是硬约束；首选分流可行时保持不变；边界不足时仅尝试同轴的有序分割（同排/同列组不拆），按最少偏离首选及最小位移选择。首选轴完整无解后，才对另一轴独立求解一次；每个结果仍只有一个轴，保留该轴的跨轴坐标、同行同列分组和原顺序，不混轴、不自由重排；两轴均无解才拒绝。
- 拖拽视觉几何与可提交布局分离：active 视觉位置仅由指针候选决定，碰撞只移动非 active 项。待确认 / 无法放置时绝不回写候选；松手拒绝时用 epoch 重挂载收敛引擎，避免旧重叠 visual 被内部 stop 留下。手势期间保持画布高度上界，防止收缩引起视口跳动。
- 静止指针也能由确认定时器触发预演；拖回原位时邻居恢复。只在松手提交整份预演，Esc / blur / touchcancel 取消整个事务并清理 timer。
- 页首进入 / 完成编辑，标题与移动把手可拖；正文 inert，卡片仅提供移动把手 / 红色删除按钮，另有显式整理布局；独立删除确认弹窗等待落盘。当前组件库原型去掉隐藏、复制和实例清单，无尺寸控件或本地尺寸预览 / 错误状态。
- 完成等待保存成功。旧 order/size/focusOrder 投影成初始矩形；positions 按 12/6/2 列断点分别保存 x/y/w/h，不覆盖其他断点、隐藏或缺席插件的记录。
- 新扩展通过可选注入的 `homeWidgets` 注册 API v1 类型；内置卡与第三方类型共用实例路径，不自动实例化目录中的新类型。公共契约以[小组件开发指南](<widget-development.md>)为准。
- 持久化实例为 `{ instanceId, typeId, configVersion, config }`；同类型可多实例；历史隐藏不删除，确认删除才清理全部断点记录。Content 自己提供配置入口，saveConfig 成功后正文切换；外壳不渲染 Settings。
- 旧 `home.widget` 仅由内部适配器保留 `{ size }` props；新安装贡献只进入目录，由用户添加。v2 布局引用过的第三方 id 按 `legacy:<id>` 迁移，不依赖当时是否安装。
- 旧 `order / size / hidden / focusOrder` 和各断点覆盖保留；类型缺失、配置迁移失败或未来版本保留原记录，以占位 / 单卡错误展示，不静默重置。
- `WidgetGallery` 是侧边真实内容预览库，名称 / 说明 / 来源 / typeId 搜索与内置 / 扩展筛选；直接拖标题或把手，不提供 Add 或额外放置模式。`preview.config/data` 提供样例，`ContentProps.preview` 标记隔离预览；没有样例时 config=默认、data=null。内置 preview provider 不构造 HomeStore，预览不请求活动 API 或启动时钟计时器。旧静态 Preview 忽略，第三方必须适配 preview 停用副作用。
- `.dsh-home-inner` 跟随宿主可用宽度，不再固定上限；不更改网格坐标或主动压缩留白。宽度变化只触发已有 12/6/2 列投影，不因浏览目录保存位置。
- 每个 widget 用对象声明自己的有限组合，如 `sizing: { default: { w: 4, h: 6 }, supported: [{ w: 4, h: 6 }, { w: 7, h: 9 }] }`；`w` 为整数 `1..12`、`h` 为整数 `3..30`，1..16 个不同组合，默认按 `w/h` 匹配；注册时克隆并深度冻结。不存在宿主统一尺寸目录。0.17 字符串只兼容解析任意合法 `WxH`，不推荐给新代码或向用户展示为目录。6 列宽投影 `w <= 4 ? min(w, 3) : min(w, 6)`、2 列 `min(w, 2)`，高度不变，实际重复形状合并。
- 新建与组件库拖入采用 `sizing.default`；`sizing.supported` 和旧 `defaults` 仅保留兼容元数据，不再提供用户可切尺寸。移动把手方向键仍逐格移动；不挂载 WidgetResizeHandle，也不维护 page local resize preview / error 或尺寸手柄样式。底层兼容模型不等于用户交互入口。
- 旧 `defaults` 校验后保留宽桶与真实 height 推导默认组合，无 ceil / 截断，旧 bounds 不定义用户可改尺寸。已保存的全部合法矩形（含旧宽1/2和声明外形状）原样保留，普通移动与显式整理不转换，不自动 reset 或 rearrange。只有旧 order/size、所有断点均无坐标的实例仍走历史 size-only 兼容；不以新默认值重新解释。API v1 与 x/y/w/h 持久化格式保持不变。公共契约以[小组件开发指南](<widget-development.md>)为准。

## 数据与操作

- `session-model.ts` 合并客户端会话目录与活动账本，目录不依赖账本整理完毕。
- 客户端 `parentId` 在 store 中转为内部 `parentSessionId`；任一来源证明空白或子代理时排除。
- 最近活动取有效的 `updatedAt / lastAt` 最大值，未知时间放到末尾，不伪造当前时间。
- 状态读取实时 `pendingInteraction.kind`，兼容旧字符串；`running: false` 只表示空闲，不代表完成。
- 目录短名使用可区分路径后缀，完整路径、会话 ID 保留在 tooltip；搜索匹配完整值。
- 草稿入口通过 `workspaces.create({ path })` 登记已有目录，再调用 `uiWorkspace.startSession`。
- 使用 `whenDraftExists: 'append'`，不覆盖已有输入，不调用模型提交接口。
- `startSession` 返回 void；异步导航失败由宿主提示，组件不能将 Promise resolve 当作导航完成。
- 目录选择使用宿主 picker，不自行扫描文件或创建目录。

### 小组件数据分层

- `widget-contract.ts` 仅公共类型与 Cordis Context 增补，分发到 `lib/types/widget-contract.d.ts`；扩展只用 `import type` 导入 `@vlln/dsh-home/widgets`，不运行时 import Home。
- `widget-registry.ts` 是无 React runtime / store / geometry 依赖的纯注册表：原子拒绝重复、稳定冻结快照、scope effect 持有撤销函数；配置工厂独立克隆，校验 / 迁移只支持同步。
- JSON 上界与持久化一致：UTF-8 序列化 8 KiB、深度 8、4,096 节点、键长 256；拒绝危险原型键、非 JSON 值和可执行属性。具体默认尺寸 / props / 失败语义见公共指南，不在各内置卡重复实现。
- `HomeStore` 通过 `workbench.get/set` 一起加载 / 串行写入实例与布局；读取失败进入只读诊断，不覆盖成默认值。设置写失败保留原配置，后续重试不被失败队列污染。
- 公共类型注册与持久化无强绑定：类型撤销保留实例，迁移失败返回原始实例及诊断；不要因缺席类型而裁剪存储。

## 显式整理与组件自有编辑

- `compactSpatialLayout` 仅由编辑模式「整理布局」调用。视觉顺序优先、逐卡 row-major first-fit，保留尺寸和元数据；已局部紧密的结果 no-op，普通拖动仍不压实。形状受限残洞可能保留，不承诺全局最优 / 无缝铺满。
- Store 整理入口拒绝非法、过期、只读、忙或实例集不完整的快照，只写当前断点，保留不可见实例及其它布局。Reset 用户入口和 store.reset 已删除。
- `Content.saveConfig?` 是持久化能力，非打开设置命令。内置组件显式选择自己的按钮与编辑器；第三方自行实现，Settings 字段兼容但不被外壳渲染。删除使用官方 Modal 与取消初始焦点。
- 当前控件专项：`DSH_VERIFY_URL='<private-instance-url>' node scripts/verify-layout-controls.mjs`；原拖拽组件库脚本已适配组件自有编辑和独立删除弹窗。

## 粘性页头缝隙与可调画布宽度（2026-11-05，0.23.1 / dsh 0.2.1-rc.5）

- **用户反馈滚动后标题“飘出来”**：不是 z-index，而是粘性元素的包含块。`.dsh-home` 的 `padding-top` 让 `.dsh-home-inner` 的顶边从 20px 起，粘性页头无法越过包含块顶边，于是滚动时停在 y=20，上方 20px 缝隙里露出卡片内容。改为把顶部净空放进页头自身 `padding-top`（`.dsh-home` 的 `padding-top: 0`），包含块顶边回到 0，页头贴到 0；实测 scrollTop 0 与 320 时 `getBoundingClientRect().top` 均为 0，顶部 3 个采样点命中元素都是页头。
- **画布宽度可手动调节**：编辑态在画布右缘出现竖向手柄（`role="separator"`），拖拽 / 方向键 / Home / End 调节，双击恢复默认；范围 960–1600px，默认 1280。存入 `prefs.canvasWidth`（`null` = 默认），宿主 `normalizePrefs` 同样夹紧，避免手改文件产生不可用画布。
  - 这是**整块画布**的一个偏好，不是组件尺寸：不写布局、不改任何保存矩形与断点，`useContainerWidth` 只是重新量一次。最小 960 保证不越过 12 列断点（950），拖动过程中不会重排。
  - 手柄放在列右侧的容器留白里（`right:-10px`，窄屏 `-6px`），避免压住全宽卡片自己的删除按钮；不越出 padding box，因此不产生横向滚动。
  - 兼容性：客户端读取偏好时把**缺失**的 `canvasWidth` 当作“未设置”（旧宿主 / 旧夹具仍可读），不会因为新增字段把偏好判为非法。
- 375 项单测（新增 4 项：夹紧与回退、拖动/键盘同值、宿主往返与手改夹紧、两端常量一致）、类型检查、构建通过。浏览器新增专项 6 项：手柄仅编辑态存在、拖动实时并持久化、刷新按保存值渲染、键盘等价、双击复位且组件不动、保存矩形与实例逐字节未变。其余视觉 / 组件库 / 释放 / 画布延展 / 固定尺寸 / 置顶回归通过。

## 画布延展与内容适配（2026-11-05，0.22.3 / dsh 0.2.1-rc.5）

- 画布取“宽度随窗口、向下无限延展”，不做二维平移缩放。基线复现（只读、拦截写入）确认消失原因是**横向**：RGL 2.2.3 只约束吸附后的落点，跟手像素不受限，指针 x=5 时卡片整张移到可视区外，向右则撑出横向滚动。纵向基线 260 帧未消失，因此纵向改动是加固而非修复已复现故障。
- 修复：经 RGL 公开 `positionStrategy` 把跟手像素 x 限制在画布宽内，y 不限；拖动期间单调保留滚动范围（候选 / 邻居 / 原始像素底部 + 一屏余量），去掉 2000px 上限；取消时恢复并夹紧起始视图，移除临时余量。存储格式与 y 上限不变。
- 标题直角白块：粘性页头仍是纯白，画布已改浅灰；改为共用画布底色。
- 热力图：自动范围按实际单元格尺寸增加整周，宽度占满且不超过 365 天；宽卡季度显示三个按时间顺序的 28 天块并把摘要放在侧边；高度预算计入行间距。显式季度 / 年份天数不变。
- **启动失败事故**：组件库预览改成 365 天样例后超过注册表 8 KiB 预览上限，`register()` 在 `apply` 中抛错，整个插件 “did not activate”。单测未覆盖真实内置注册，故未拦截。样例移入 `activityPreviewSnapshot()` 恢复 84 天，新增经真实注册表校验的回归测试（含超限负控）。
- 371 项单测、类型检查通过。浏览器：画布 4 项（横向不逃逸、静止贴边纵向延展 >3000px 不跳不消失、Escape 回滚、断点切换取消）、视觉、释放、组件库、固定尺寸、置顶全部通过；11 种宽度 × 范围组合热力图均无外层溢出。断点用例原有竞态（视口改变后 React 尚未重渲染即松手），已改为等待列数真正切换。用户实例与布局逐字节未变。
