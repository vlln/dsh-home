# 0003 — 布局只存覆盖，不存完整排布

- 日期：2026-10-22
- 状态：采纳

## 背景

用户可拖动排序/切尺寸/隐藏。布局落盘有两种写法：存完整快照，或只存用户动过的部分。

## 决定

只存 `{ order: string[], size: Record<id, 's'|'m'|'l'>, hidden: string[] }`，
且 `order` 只记被移动过的 id、`size` 只记被切过的 id。默认排布每次由「内置表 + `home.widget`
注册顺序」合成，用户覆盖叠加其上。

## 理由

- 卸载一个 widget 包不会毁掉别人的布局；新装一个包默认出现在它的 order 位置。
- 布局文件不会因为内置卡增减而携带死 id。
- `order` 里只留移动过的最小集合，后续新增卡片不会被"末位"吞掉。

## 代价

- 两处合成逻辑（`store.ordered` + page 的 metas）必须一致；单测覆盖不到 UI，靠渲染验证。
- widget id 成为事实上的稳定契约——写进 README。
