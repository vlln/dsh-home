# 0004 — 阅读态/编辑态分离 + 两步确认

- 日期：2026-10-22
- 状态：采纳

## 背景

首页要同时承担"看"和"改布局"。可选形态：常驻编辑控件（每张卡永远挂一个 kebab 菜单）、
独立设置页、或一个显式的编辑态。

## 决定

- **阅读态零编辑控件**：卡片只有数据与可点的行；所有编辑能力（拖拽把手、尺寸、隐藏、
  小组件清单、恢复默认、重建账本）都在「编辑布局」进入后的编辑态里，`Esc` 分层退出。
- **"恢复默认"用两步确认**（按钮变红 → 「确认恢复默认？」→ 4 秒自动取消），不弹 Modal：
  低频、可恢复的动作不值得一个对话框。
- **小组件清单取代"全部显示"**：每张卡一个显式开关，也是将来"添加第三方 widget"的入口。

## 代价

- 拖拽只在编辑态可用（阅读态无法直接拖动）——换来的是阅读态不会误拖。
- 编辑态是组件局部状态，离开面板即丢失；这是有意的（不把临时状态带进会话）。
