# 0005 — 首页默认形态：三件事 + 更多（不做报表）

- 日期：2026-10-23
- 状态：采纳

## 背景

0.1/0.2 的默认形态是一张六卡的网格仪表盘。对照同类产品后发现两件事：

1. **报表会衰减**：Google Now、Windows 磁贴、Notion 手工面板都死在"看过就忘"——数据卡不改变用户下一步做什么。
2. **home 的赢家都是队列 + 记忆**：GitHub 首页、Linear Inbox、Slack 动态回答的是"自上次以来变了什么、什么在等我"，并且都能 dismiss / 标已读。

另外两个约束把网格形态顶到了墙角：

- **N=1 用户**：普通用户一天 1–3 个会话，六张卡五张空，空仪表盘比原生首页更糟。
- **布局编辑器是一次性新鲜感**：维护成本最高（碰撞、拖拽、持久化），使用频率最低。

## 决定

默认是**三件事**（`focus.tsx`）：回到现场（带最后一句人类输入）、在等我（官方 `sessionStatus` 的待审批/跑完没看）、今天（一条时间带 + 一个主数字）。
可编排的网格退到「更多数据与小组件」里（opt-in），编辑态只作用于那一层。

同时补上"记忆"：`prefs.lastSeenAt` 支持「自上次以来 N 个会话有动静」；`prefs.dismissed` 让 dismiss 只静音**到下次有新活动**为止。

## 代价

- 删掉「继续 / 今天动过」两张卡（前者被"回到现场"取代，后者与列表同构）；「今天按工作区」并入"更多"。
- 「在等我」的完整度受官方 `sessionStatus` 限制：没有它就只有空态（卡片会明说）。
- 首页不再一眼看到全部数据——这是有意的取舍：**首页先解决"接着干什么"，数据是第二层**。
